C++ · SDL · data structures

            
Red-Black Tree Visualizer

            
A C++/SDL engine that animates every insert, delete, and lookup in a red-black tree —
               recolorings and all four rotation cases rendered step by step as the tree rebalances,
               with the layout reflowing to avoid crowding.

            
Shipped with a full written report and presentation on the balancing invariants.
               The demo here is the same fixup logic, re-implemented in JavaScript so you can poke it:
               insert values and watch it rebalance.
